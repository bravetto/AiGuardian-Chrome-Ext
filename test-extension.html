🧪 AI Guardians Chrome Extension Test Page

📋 Testing Instructions

  1. Load the Extension: Go to chrome://extensions/, enable Developer mode, click "Load unpacked" and select this directory
  2. Test Text Selection: Select any text below and wait for the bias analysis badge to appear
  3. Test Options: Click the extension icon and then "Open Options" to test the configuration interface
  4. Test All Guards: In options, click "Run Comprehensive Tests" to test all 6 AI Guardians

✅ Expected Results

  • Text Selection: When you select text, you should see a colored badge appear in the bottom-right corner
  • Bias Scores: Green (low bias), Orange (medium bias), Red (high bias)
  • Analysis Details: Click the badge to see detailed analysis results
  • Options Page: Should show all 6 guard services with configuration options
  • Testing Interface: Should run comprehensive tests for all components

🐛 Troubleshooting

  • Extension won't load: Check that all files are present and manifest.json is valid
  • No analysis badge: Make sure you select at least 10 characters of text
  • Options page errors: Check browser console for JavaScript errors
  • Tests fail: Check that all dependencies are properly loaded
